Installation
============

Requirements
------------

- Python 3.8+
- MNE-Python
- PyTorch (for data loading)

Install from source
-------------------

.. code-block:: bash

   git clone https://github.com/AndersGMadsen/SPEED.git
   cd SPEED
   pip install -r requirements.txt
   pip install -e .

Development install
-------------------

.. code-block:: bash

   pip install -r requirements_dev.txt
   pip install -e ".[dev]"
