SPEED Documentation
====================

**SPEED** (Scalable Preprocessing of EEG Data) is a configurable EEG preprocessing pipeline
for self-supervised learning and downstream evaluation.

It processes raw EEG files (EDF/BDF/SET) into standardized, quality-controlled windows
stored as HDF5.
